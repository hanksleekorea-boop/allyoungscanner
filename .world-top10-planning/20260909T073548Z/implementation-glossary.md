# 구현 용어집

- PUBLIC_VERIFIED: 공개 URL에서 직접 확인
- IMPLEMENTED_VERIFIED: 코드와 자동/실행 증거 모두 확인
- IMPLEMENTED_UNVERIFIED: 코드 존재, 운영 왕복 미확인
- BLOCKED_EXTERNAL: 권한·계약·비밀값 등 외부 입력 필요
- R2 STATIC: Cloudflare R2 객체를 Worker가 정적 자산으로 제공
- WeSaver OAuth: 사용자가 지정한 기존 Google OAuth 프로젝트 계약; 새 OAuth를 만들지 않음
- X10_PARTIAL_SCOPE: 10배 탐색 계약을 충족하지 못했지만 실제 조사 범위와 한계를 기록한 상태
