# 올영스캐너 통합 제품기획 vNEXT (v3.2 실행본)

## 제품 정체성

올영스캐너는 올리브영과 독립적인 글로벌 뷰티 쇼핑 탐색 허브다. 사용자는 제품·브랜드·GTIN을 검색하고, 근거·성분·용량·가격·판매처를 비교한 뒤 실제 판매처로 이동한다. 제휴·광고는 구매 판단과 분리하고 모든 상업 관계를 명시한다.

## Outcome

사용자가 90초 안에 “무엇인지→왜 고려할지→어디서 확인할지→나중에 다시 찾을지”를 이해하도록 한다.

## 전략

1. 권리·출처·확인일을 상품 단위로 표시한다.
2. 정확 SKU·옵션·지역·가격 신선도를 검증하지 못하면 구매 확정 표현을 금지한다.
3. 로그인 없이 핵심을 제공하고, WeSaver Google OAuth는 선택적 계정 백업으로만 사용한다.
4. 모바일 매장 모드와 PC 근거 비교를 하나의 데이터 계약으로 연결한다.
5. 5단계 계획은 외부 조건을 완료로 위장하지 않는다.

## 목표 지표

검색 성공률 ≥95%, 0건 회복률 ≥80%, 정확 SKU 도착률 ≥95%, 저장/복원 성공률 ≥99%, OAuth callback 성공률 ≥98%, P95 LCP ≤2.5초, 중대 데이터 손실 0. 실제 목표값은 표본·지역을 함께 기록한다.

## 범위 밖

의료 진단, 올리브영 공식 서비스 사칭, 임의 가격·재고 보증, Apple 로그인, 결제·구독, B 드라이브, OpenAI 런타임 의존.

## 인수 기준

P0 요구사항과 실제 증거가 모두 연결되고, Android·OAuth·운영자·법률·제휴 외부 조건을 별도 승인한다.
